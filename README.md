

# Задачи
1. Реализовать класс Student и паттерн Builder (model/Student) ✅
2. Реализовать кастомную коллекцию StudentList (collection/StudentList)
3. Создать реализации интерфейса сортировки (strategy/SortingStrategy) по всем трем полям
- Также реализовать отдельную сортировку по числовому полю (четные элементы сортируются в натуральном порядке, нечетные остаются на исходных позициях) 
4. Реализовать интерфейсы и реализации для загрузки/сохранения данных в коллекцию через файлы (service/FileService). ✅
- При сохранении коллекции в файл используется режим добавления данных
- При загрузке из файла нужно использовать стримы для заполнения коллекции
5. Реализовать CLI для взаимодействия (App) ✅
- Написать базовый набор команд
- Реализация выбора команды:
```
switch(commandName) {
    case caseName -> {
    ...
    }
    case caseName -> {
    ...
    }
    ...
    default -> {
    }
}
```

6. Релизовать многопоточный подсчет количества вхождений элемента N в коллекцию. Результат выводить в консоль (service/SearchService)


# Для загрузки изменений
1. Создать отдельные ветки
```
git checkout -b feature/название_ветки
```
2. Загрузить ветку
```
git push origin feature/название_ветки
```
3. Создать Pull Request

4. Перед дальнейшей работой загрузить изменения
```
git pull origin main
```
